# The One-Line Cat Joke That Lands

A [make.fun](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) entry: a tiny Node program (`main.ts`) that writes exactly one line — the funniest possible cat joke, under 200 characters — to `/output/entry.txt`. Deterministic: every run produces the same line.

Run it with `node main.ts` (Node 22+). Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` goes.
